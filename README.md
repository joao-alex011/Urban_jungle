#URBAN JUNGLE HELPER


O UrbanJungle Helper é uma aplicação web desenvolvida para ajudar amantes de plantas a organizar, cuidar e aprender mais sobre sua coleção botânica. Com uma interface amigável e focada na usabilidade, o projeto oferece desde um checklist diário de tarefas até uma enciclopédia completa de espécies.

Funcionalidades:

Minhas Plantas: Gerencie sua coleção pessoal de plantas.
Nova Planta: Adicione novos exemplares à sua selva urbana (com a opção de usar templates da enciclopédia).
perfil das minhas plantas: gerencie as informações da suas plantas
Tarefas (Checklist Diário): Acompanhe o que precisa ser feito no dia (regar, adubar, podar, etc.) com uma barra de progresso interativa e a opção de limpar tarefas concluídas.
Enciclopédia / Catálogo: Consulte uma lista detalhada de espécies domésticas (como Costela-de-Adão, Jiboia, Zamioculca).
Filtre plantas por nível de luz e exigência de água.
Visualize informações vitais como toxicidade para pets.
Cronograma: Planeje os cuidados a longo prazos
configuraçoes: faça ajustes para ajudar a gerenciar suas plantas

tecnologias usadas:
CSS , HTML e Java script basico
